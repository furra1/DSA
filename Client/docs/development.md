# Development

1. Install JDK 21 and Gradle 8.10 or newer.
2. Run `gradle test` from `Client/`.
3. Run `gradle build` to compile and package the client library.
4. Keep dependency versions in `gradle/libs.versions.toml`.
5. Do not add UI code until the product design is available.

No C# or server files are modified by this client project.
